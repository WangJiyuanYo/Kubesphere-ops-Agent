## 隔离界面验收

以打包 Jar 启动临时 SQLite 服务和仅本机监听的 Python 平台 / 集群替身，默认演示身份，模型与真实恢复关闭。经页面完成登录、阶段查看、创建明确范围 DIAGNOSE 策略、无 CR 人工处置记录、时间线与站点暂停；暂停按钮切换为“恢复观察与托管”。同站点只生成一个调查与 DRAFT 出队记录。两个临时服务在验证后关闭，临时库和日志位于忽略的 `tmp/provisioning-ui/`。

关闭后以只读连接核验临时 SQLite：站点、调查触发、学习出队、策略、站点暂停审计各 1 条，paused=1，恢复 Run=0，符合无 CR 场景不创建恢复任务的预期。

截图均为隔离契约场景，不能用来证明 8100 或平台已经上线。截图采集后补充了列表“已暂停”标记与统计说明文案，UI 自动化再次通过。
