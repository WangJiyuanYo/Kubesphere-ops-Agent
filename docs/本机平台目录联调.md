## 2. 在本机验证并配置平台身份

在 `http://localhost/` 正常登录有 KubeSphere 管理查看权限的账号。浏览器开发者工具的网络请求中，可查看该登录会话发往本机后端的 Authorization 头；输入脚本时仅使用 Token 部分，去掉 `Bearer `。

在 Windows 终端运行，入口会优先使用 PowerShell 7，没有时使用系统自带的 Windows PowerShell 5.1；无需管理员权限，也不修改系统执行策略：

```powershell
cd D:\codes\deployment-ops-agent
.\scripts\configure-local-platform.cmd
```

脚本默认请求 `http://127.0.0.1:8081/api/admin/integrations/kubesphere/agent/provisioning-instances?page=1`。也支持读取当前 PowerShell 进程已配置的 PLATFORM_TOKEN；不需要把 Token 发到聊天。

脚本仅在目录返回200、业务code=200、分页格式和字符串ID均合法时，使用 Windows 当前用户 DPAPI 保存加密Token。文件位于 `secrets/local-platform/token.dpapi`，配套非敏感基址位于 `base-url.txt`，均在Git忽略目录内。目录ACL限制为当前用户。401、403、404、重定向、超限或异常响应均拒绝保存，不覆盖旧凭据，不显示上游错误正文。

会话 Token 有平台有效期，后端重启也会使其失效。文件存在不代表当前可用，接入前仍需重新鉴权；本项目没有创建永久平台身份或延长用户会话。

## 3. Agent 运行配置

经验证的Token用于本机Agent进程环境，不能写到源码、普通配置或日志：

```text
AGENT_PLATFORM_CATALOG_ENABLED=true
AGENT_PLATFORM_CATALOG_ALLOW_LOOPBACK_HTTP=true
PLATFORM_BASE_URL=http://127.0.0.1:8081/api/admin/integrations/kubesphere/agent
PLATFORM_TOKEN=<从本机加密文件解密后仅注入目标进程>
```

本机目录启动入口显式保持DEMO恢复，只启用只读平台目录，不复用页面集群Token进行写入。运行中的Agent需要重启才能加载部署配置。执行：

```powershell

.\scripts\start-local-platform-agent.cmd -Restart
```

入口读取本机加密Token并先重新鉴权；校验8100是本项目预期的SQLite Java进程，拒绝停止其他应用。随后使用Python标准库检查活动恢复、未过期对话及排队/运行中调查，在线备份SQLite并配套复制主密钥，再核对原PID与创建时间后重启；Token仅注入子进程环境，不作为命令参数或日志。需要已安装Python和本机JDK21；默认路径与已验证runtime运行包一致。启动后检查健康UP，进程仍活着但观测超时不自动重放启动。启动日志在runtime/local-platform-agent.log和local-platform-agent-error.log。
