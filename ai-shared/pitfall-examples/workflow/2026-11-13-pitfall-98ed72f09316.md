# PIT-98ed72f09316: 意图预算不能充当已执行恢复的可信证明

| 日期 | `2026-11-13` |
| 领域 | `workflow` |
| 标签 | 状态机, 自然收敛, 记忆可信度 |
| 来源 | 部署运维 Agent 2026-11-13 业务闭环复审与修复 |

## 需求

只有已经受理并通过稳定验收的恢复动作才能自动成为已验证经验。

## 现象

持久化意图后现场自然恢复，平台未收到恢复调用，建议却因为 attempts 大于零自动归档为 VERIFIED。

## 错误做法

```text
归档仅判断 run.state == SUCCEEDED、attempts > 0 和 plan 存在。
```

## 根因

把意图次数与实际受理动作混为一谈，再把终态成功推导为原建议有效。

## 修复方案

```text
统一 verifiedRecovery 判断固定动作键、非空受理凭据、恢复成功及稳定验收；自然收敛与旧无凭据出队降级为 DRAFT，迁移重新核验旧自动经验。
```

## 预防规则

区分计划、意图、受理、完成和因果证明；成功知识必须引用可信动作与验收证据，覆盖自然收敛、无凭据和历史队列重放。

## 验证

双库自然收敛与历史出队降级测试、记忆迁移和完整恢复召回通过；最终 verify 230 项无失败。
