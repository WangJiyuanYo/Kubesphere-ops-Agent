# PIT-0db364bd0a9b: 只读目录详情错误复用恢复快照导致监控被验收配置阻断

| 字段 | 值 |
| --- | --- |
| ID | `PIT-0db364bd0a9b` |
| 日期 | `2026-11-13` |
| 领域 | `api` |
| 标签 | 只读目录, 契约, 恢复门禁 |
| 来源 | 独立部署运维 Agent 与租户平台的生产者消费者契约回归 |

## 需求

有权查看项目的用户可以仅凭只读连接加入监控；恢复继续核对独立身份、完整目标和验收配置。

## 现象

列表允许监控，但关联操作返回 AGENT-PROFILE-409，未能保存 namespace 监控范围。

## 错误做法

```text
PlatformCatalogGateway.current(id) 调用 /provisioning-instances/{id}；snapshotData 要求 profile(project)。
```

## 根因

查询场景不同却共用恢复前提。单独为消费者构造理想响应的测试未覆盖真实生产者的拒绝分支。

## 修复方案

```text
新建 /provisioning-instances/{id}/catalog-entry，先校验同一数据范围授权后返回项目映射；恢复快照保持原门禁。
```

## 预防规则

按业务意图区分只读映射和恢复快照。导出真实生产者响应供消费者解码回归，并覆盖目录正常、缺少恢复配置、关联仍可读取。

## 验证

平台 DeploymentAgentContractServiceTest 证明只读映射成功且严格 snapshot 仍为 AGENT-PROFILE-409；Controller 路由、匿名拒绝、Agent PlatformCatalogGatewayTest 消费生产者导出的 fixture 全通过。
