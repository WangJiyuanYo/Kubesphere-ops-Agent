## 需求

运维对话应能说明已保存的连接信息，选择环境后读取获准的本轮只读快照，并区分配置与实时证据。

## 现象

页面已有连接，模型仍要求用户重新提供连接；用户选择连接后，回复继续说没有本轮集群数据。

## 错误做法

```text
只在会话绑定连接时附加连接名称与命名空间；未绑定时完全不传配置目录。页面选择连接后没有启用本轮快照选项。
```

## 根因

把页面或数据库中存在的信息误当作模型已经可见的上下文，同时把选择环境与实际采证两个开关的关系隐藏给用户。模型只能看到显式传入的消息，无法自行读取数据库或调用集群。

## 修复方案

```text
未绑定会话提供受预算限制的安全连接目录，不访问集群。绑定会话始终传递连接元信息；页面选择或恢复关联后默认勾选快照，允许关闭，服务端仍按本轮选择采证。连接身份和当前采集优先于长历史；采集失败明确缺口，不混用其他环境，不向模型传递凭据。
```

## 预防规则

逐项追踪页面配置、服务端持久化、上下文构建与模型实际输入；分别验收未绑定、仅元信息、成功快照、采集失败和失效身份，不能用模型的自然语言承诺代替采证。

## 验证

独立 PostgreSQL 与临时 SQLite 回归均验证安全目录无集群请求、显式快照读取、失败缺口和失效发现身份禁止采集；完整 Maven verify 为 172 项零失败零跳过。本机页面另行验证默认勾选和失败后手动重新提问；真实连接对话确认元信息和本轮 Pod 证据可见。
