## 产品目标与范围

运维人员在同一服务提供的简单页面中配置模型、管理 KubeSphere 连接、与 Agent 对话，并查看部署任务。页面与 Java 服务一起打包，不需要额外前端服务或 CDN。

提供六个入口：Agent 对话、排障记忆、KubeSphere 连接、LLM 设置、部署任务、站点开通。桌面采用侧栏，窄屏采用可横向滚动的导航，并保留退出入口。

站点开通展示阶段时间线、观察降级、调查案例、关联 Run、托管策略及恢复效果样本。策略默认关闭，编辑须携带 revision 并冻结身份范围；原版本排队结果不能取得新版本授权。无 CR 错误也可查看，平台成功不等于应用验收。详细规则见[站点开通与自动托管 PRD](站点开通与自动托管_PRD.md)。

## 用户角色与场景

使用现有运维账号登录，账号由服务端环境配置管理。所有授权运维人员共享同一工作空间、连接、配置和对话；当前不提供个人会话隔离、多租户、注册或改密页面。

首次登录可直接体验规则助手，配置模型后可进行自由对话和任务证据分析。KubeSphere 连接是对话和部署发现使用的只读数据源；部署恢复工作流继续使用服务端 ServiceAccount / kubeconfig、平台地址和允许命名空间。

## 当前功能规则

### LLM 设置

- 支持 DashScope 原生协议和 OpenAI 兼容协议。填写启用状态、Base URL、模型名称、API Key、Temperature（0–2）和最大输出 Token（128–4096）。默认模型 qwen-plus，Temperature 0.1，最大输出 1500，未启用。
- 模型名称旁提供“获取模型”：按当前表单的协议、地址和密钥读取目录，无需预先保存、启用模型或填写模型名。新填密钥仅用于本次请求；留空时仅在版本、协议和标准化地址均与已保存配置一致时复用原密钥。勾选清除时拒绝获取，更换目标须重新填写密钥。
- 获取中禁用按钮；成功后显示数量与模型下拉框，不自动改写当前模型。用户选择后填入模型名称，保存后生效；仍可手工填写。修改地址、协议或密钥后列表失效，迟到响应不覆盖新表单。空列表或获取失败保留原模型并提示手填；目录可见不代表账号支持推理，须保存并测试连接。
- OpenAI 兼容协议读取 `{baseUrl}/models`；DashScope 原生读取同一根地址的 `/compatible-mode/v1/models`。只接受标准 `data[].id`，过滤非法项后去重排序，最多提供 500 项并提示截断；响应上限 1 MiB。此操作不保存配置、不调用推理、不跟随重定向，错误不返回上游正文。
- DashScope 地址填写根地址；OpenAI 兼容地址包含 `/v1` 等前缀，服务端追加 `/chat/completions`。保存后可测试连接，测试会产生一次实际模型请求。关闭启用开关后仍允许对已保存凭据进行连接测试。
- 配置保存后对后续对话和 Graph 故障诊断生效，不中断正在执行的请求。已保存控制台配置优先于启动环境的模型诊断设置；关闭页面模型会让诊断回退手册。尚无页面配置时，诊断兼容启动配置，对话使用规则助手。
- GET 仅返回是否已保存密钥，不返回明文或密文。API Key 留空保留原值，勾选清除才删除；启用模型必须存在密钥。更换服务地址或协议时必须重新输入密钥或明确清除。
- 使用版本号拒绝覆盖其他操作员已更新的配置，冲突后刷新页面重新编辑。

### KubeSphere 连接

- 可新增、编辑、删除多条连接；字段包括名称、Kubernetes API 网关地址、可选控制台链接、命名空间、Token 和可选 PEM CA 证书。控制台链接可以直接打开。
- 网关地址必须能代理 Kubernetes API。多集群网关可以填写包括集群代理前缀的完整基址。测试固定执行 `GET {apiUrl}/api/v1/namespaces/{namespace}/pods?limit=10`，展示连接结果及返回数量。
- 只读快照最多包含 10 个 Pod 的名称、phase、Ready 条件及采集时间。测试不是平台恢复接口、Operator CR 权限或完整集群健康的验收。
- Token 加密保存、不回显；留空保留、显式清除，更换 API 地址须重输或清除。HTTP 请求不跟随重定向，不向其他地址转发凭据。
- 自定义 CA 最多 32768 字符、10 张 X.509 CA 证书，不接受私钥或普通服务端叶子证书，仅适用于 HTTPS。CA 独立加密保存、不回显，接口只返回 hasCaCertificate；留空保留、显式清除，更换 API 地址须重输或清除。仅该连接使用专用信任集合，证书链与主机名校验保持开启；不改变全局信任或工作流身份。旧连接未保存 CA 时继续使用系统信任。
- 删除连接保留历史对话与文本，解除可用连接关联；原会话不能继续读取或混入其他环境，须新建对话。新会话在事务内冻结 API 和命名空间身份；后续修改任一目标字段时旧会话停止采证和模型调用。同目标名称修改、凭据轮换可继续。升级前缺少冻结身份的旧关联会话保留历史，继续调查须新建。

### Agent 对话

- 可新建会话、选择历史会话、刷新对话、发送文本。首条消息前可关联一个部署任务与一个 KubeSphere 连接；关联后固定，会话恢复时显示原关联。
- 同时关联恢复任务和连接时，服务端核对任务创建时的环境、执行集群及所有目标命名空间；不匹配返回 409，不创建混合会话。模拟任务不能与真实只读连接混用；每轮再次核验，不能绕过创建接口后触发错误采证。
- 每条消息最多 4000 字符。未关联连接时提供已保存连接的安全目录：名称、ID、API、命名空间及可选控制台地址，最多 10 条且受上下文字符预算限制，截断时明确提示；不读取集群、不提供 Token / CA / 主密钥。模型可据此帮助选择环境，不能把配置目录视作实时连通或健康证明，也不能根据文字自动切换集群。
- 关联连接时始终提供其名称、ID、API、控制台地址与命名空间。页面选择连接、恢复已关联历史会话或从发现任务进入对话时，默认勾选“自动只读排查”，发送前仍可关闭；API 继续以本轮 includeCluster 为准，无关联时不可读。侧栏显示当前目标与本轮采集选择，每条历史消息标明是否请求快照。切换环境仍需新建对话。
- 普通连接会话勾选采证后，执行只读排查 Graph，按名称或异常优先采集最多 2 个 Pod 的容器状态、事件、当前及上次退出日志，详见[对话只读排查 PRD](对话只读排查_PRD.md)；关联发现任务的会话则按任务实际 namespace 采集归属工作负载、容器状态、相关事件与有界日志，优先异常目标且显示采证缺口。成功上下文含采集时间和 Pod 状态；网络、TLS 或权限失败明确标记采集缺口，仍可基于配置、任务证据进行对话，不能把失败当成空清单或健康结论。发现任务身份不匹配、删除或换址仍拒绝处理，不降级成另一环境的采集。连接与本轮快照优先于长任务方案，历史回答不覆盖当前事实。任务上下文仍含当前状态、恢复次数、最新证据和已有方案，不读取任意集群或 Secret。
- 启用模型时使用当前模型、最近最多 6 个成功轮次和本轮上下文。未启用时显示规则助手与上下文摘要。模型失败保存 FAILED 轮次，来源为“模型服务”，展示本地 LLM 错误类别及可用的 HTTP 状态，不伪造成功回答；区分凭据配置、401 认证、403 权限、模型不支持、接口路径、429 限流 / 额度、上游不可用、超时、网络 / TLS、空响应及协议格式问题。页面不显示上游正文，服务端只记录类别、HTTP 状态和耗时。
- 失败消息的“重新提问”只将原问题与原快照选择填回输入区，用户确认发送后用新 requestId 发起一次新请求；原失败记录保留。同一原 requestId 仍幂等返回原结果，失败、超时不自动重发模型请求，也不把失败轮次加入成功历史。
- 会话标题、消息、证据和输出按当前脱敏规则处理；脱敏文本单段最多 4000 字符。历史查询展示最近 50 个会话、每会话最近 50 轮；存储暂不自动清理。
- 同一请求身份重放返回已有结果，不重复模型调用；不允许同一身份更改内容或上下文。同一会话串行，全局默认 4 个聊天槽位，90 秒租约过期后允许新消息接管，迟到结果不能覆盖新状态。多实例各有自己的并发上限。
- 聊天支持有审计的只读 API 采证与分析，不能执行自由命令、恢复或资源写入。回答中的修复建议不构成执行授权；恢复动作继续由现有预算、批准、手册和验证流程管理。
- 自动参考实际调查来源范围内最多 3 条已验证排障记忆，在回复下展示可打开的来源引用；真实连接不参考模拟或其他 API / namespace 案例，无目标会话不自动召回。历史引用随轮次保存，刷新会话后保留。成功关联回复自动进入待确认复盘队列，可点击“查看自动复盘”，也可人工记录为待确认排障思路，重复保存同一轮次不重复建单。未启用模型时，规则助手也能展示命中的历史思路。

成功或失败的结束轮次均可展开“本轮集群采证记录”，核对实际 API 请求、HTTP 结果、采证时间、脱敏证据与权限缺口；模型失败不丢弃已保存的采证。历史无审计轮次不补执行。

### 对话 Markdown 展示

成功的助手回复支持 Markdown 段落、换行、标题、粗体、斜体、删除线、有序 / 无序及嵌套列表、引用、分隔线、行内代码、代码块和表格。历史成功回复按相同规则展示，数据库继续保存原始脱敏文本；用户问题、失败消息及处理中提示保持纯文本。

代码块保留缩进与换行；长代码和宽表格在消息内部横向滚动，窄屏不撑开整页。仅完整的 HTTP / HTTPS 链接且不带内嵌账号密码时可点击，新标签打开并隔离来源页、隐藏来源地址；相对地址及其他协议仅显示文字。图片仅显示说明，不发起加载；原始 HTML 显示为文字，不能执行脚本或插入表单。解析与净化库本地打包并保留 CSP，依赖缺失或渲染失败时降级为原始纯文本。

### 排障记忆

支持中文和技术词检索、按待确认 / 已验证 / 已归档过滤，以及记录、编辑和归档。填写验证依据才可标记已验证，归档后不自动召回。页面显示当前主存储类型和 FTS5 检索方式，最多展示 50 条结果，无匹配时显示空态；保存失败保留表单内容。字段、可信状态、自动归档与来源规则详见 [SQLite与排障记忆_PRD.md](SQLite与排障记忆_PRD.md)。

### 部署任务

任务页提供接入状态，展示规则 / 模型配置、已保存连接及监控清单、上次扫描时间与失败、平台目录、DEMO / 真实恢复、验收档案和 kubectl 配置。配置状态不等于当前连通，历史扫描也不等于实时健康；查看和刷新此面板不触发模型、扫描或恢复。每个任务的门禁继续独立校验，侧栏不再无条件显示“Agent 已就绪”。

「集群部署发现」按连接启用 / 暂停，后台读取该连接独立配置的 1–20 个命名空间内四类 Operator CR，默认 namespace 的编辑不改变监控清单；支持页面保存范围，不允许通配符。首次同步收录当前清单；同资源 UID / generation 去重，新代次单独记录。发现仅持久化状态，不调用模型。用户自行忽略或「交给 Agent」，后台重新核验身份并通过诊断 Graph 生成只读方案；可查看来源、采证时间、失败信息及选择操作员。支持连接 / 处理状态筛选与每页 30 条分页。

集群 phase 与 Agent 的待接管 / 排队 / 排查 / 已有方案 / 失败 / 忽略分开展示。被替代、已缺失或换址的历史资源不能接管；同步错误不当作资源删除。选择后不执行 kubectl、平台重试或集群修改，方案也不代表恢复成功。「询问 Agent」固定关联发现记录和原连接，历史会话保留此上下文，成功对话可记录思路。同一案例可显式关联受控恢复并在原会话查看状态和证据，不会将对话建议当作实际执行。详细规则见 [部署发现与手动接管 PRD](部署发现与手动接管_PRD.md)。

「已接入恢复流程」继续展示最近 30 个平台注册或演示任务的任务号、状态、恢复次数与时间，可查看详情并在新会话中关联该任务。详情包含命令计划、安全结论、执行状态和脱敏结果（最多 100 条审计 JSON），并显示诊断保存的审计引用。命令采证由服务端配置，不提供自由输入或聊天执行按钮。普通任务详情与案例详情均提供当前低风险方案的批准、未下发动作的停止及刷新，批准必须使用最新 planId，动作已下发时不显示停止。任务页每 5 秒刷新。DEMO 模式可创建模拟任务；真实模式无演示按钮。发现案例详情可预览平台完整目标、确认转交、查看关联恢复、批准当前低风险方案或在动作下发前停止；通知重投继续通过 API 完成。恢复入口需要严格平台契约与同集群独立执行身份，显示未满足条件的阻断原因，不能用页面只读 Token 代替。

## 权限、数据与接口语义

页面登录壳及指定本地展示资源公开，`/api/console/**` 与既有业务 API 需要 OPERATOR 认证。浏览器认证凭据仅保留当前页面内存，刷新后重新登录。控制台写请求必须带 `X-Console-Request: 1`，有 Origin 时须与 Host 同源。服务端使用 CSP 限制脚本和资源来源；成功助手回复仅渲染净化后的 Markdown 排版元素，其他动态内容按纯文本呈现。

模型和连接配置、会话及轮次存储于所选主库：默认独立 PostgreSQL，可选完整 SQLite。SQLite 模式下 KubeSphere 名称、API 地址、控制台链接、命名空间和加密 Token 全部保存在 SQLite 主文件，重启后可读取。记忆在 SQLite 模式下复用主文件，PostgreSQL 模式下使用独立 SQLite 记忆文件。凭据使用 AES-256-GCM 加密，并绑定其用途或连接身份。服务端可注入 Base64 编码的 32 字节主密钥，或首次保存凭据时生成本机密钥文件。密钥文件和数据库必须配套备份，缺失原密钥时需要恢复原文件或重新填写凭据，不能凭空还原。切换主库不自动迁移历史数据。

`BUSINESS_DICTIONARY_OR_CONFIG`：模型服务类型属于协议代码枚举；模型下拉选项来自当前网关的实时目录，不使用硬编码业务字典，手填用于兼容未公开目录的服务。模型地址、最终选择的名称、凭据和采样参数、KubeSphere 网关和命名空间属于操作员维护的运行配置。重试预算、动作类型、执行授权、部署命名空间与平台恢复地址继续由服务端策略控制，页面不修改这些策略。

## 异常与恢复路径

- 登录失败显示错误，匿名业务请求拒绝。登出清除内存认证和密码输入。
- 模型失败显示分类错误并保留失败轮次；模型诊断仍回退手册。快照网关失败记录证据缺口，允许继续分析已有上下文；身份不匹配仍拒绝。两者均不输出上游错误正文或凭据，不通过放宽 TLS 或自动重发隐藏故障。
- 消息请求超时后可刷新对话检查原消息；未到期的处理中消息不能被并行替换，租约过期后可继续发送。
- 配置并发更新返回冲突；重新登录或刷新后编辑最新版本。关联任务不存在时拒绝创建会话。
- 默认配置地址只接受 HTTPS 且不带内嵌用户信息、查询参数或片段。本机联调可由服务端明确开启 HTTP；不关闭证书校验来兼容自签证书。

## 非功能需求与现场边界

模型连接超时 5 秒，读取超时默认 45 秒，可通过服务端 AGENT_MODEL_READ_TIMEOUT 在 100ms 至 45s 范围配置，启动时校验上限以适配外层请求预算；单次尝试。KubeSphere 连接超时 5 秒、读取超时 10 秒。浏览器请求超时 65 秒，聊天租约 90 秒，失败可刷新恢复记录。对话非流式返回；延长默认读取预算不保证上游一定成功。

通过反向代理对外提供页面时使用 HTTPS，反代应保留外部 Host。生产主密钥使用 Secret 注入，或挂载有访问控制的持久卷；不能依赖容器临时文件。所有授权账号具备配置外部服务地址的权限，服务端网络访问范围应按部署环境限制。

安全设计参考 OWASP [Secrets Management Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Secrets_Management_Cheat_Sheet.html) 的密钥生命周期与访问控制，以及 [Cross-Site Request Forgery Prevention Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html) 的自定义请求头和来源核验建议；当前仍为共享运维账号工作空间。

## 验收标准

1. 未配置模型可登录并发送规则对话；匿名配置、会话请求拒绝。
2. 保存后读取设置不含凭据；数据库无原始 API Key / Token。留空保留，更换地址不能隐式沿用旧凭据，旧版本保存拒绝。
3. 两种模型协议向正确路径发送结构化消息；连接测试成功；失败及重定向不泄漏凭据。
4. KubeSphere 测试读取指定命名空间的 Pod，返回 Ready 状态；无权限或非列表响应明确失败。
5. 保存模型后对话与 Graph 诊断热生效；诊断错误回退手册，关闭后不再请求模型。
6. 重新登录可恢复会话；重复请求不重复调用；处理中不能并发；过期回复不得覆盖新轮次。
7. 未绑定会话可读取安全连接目录且不发起集群请求；选择或恢复已绑定会话默认勾选快照，可关闭。选择后包含目标元信息，成功快照包含本轮 Pod，采集失败明确缺口而不阻断模型对话，失效发现身份不读取新环境；聊天不创建恢复动作。
8. 任务列表、详情及询问 Agent 可用；窄屏页面无整体水平溢出且可退出登录。
9. SQLite 下保存 KubeSphere 配置、LLM 和聊天后重启仍能读取，响应与输入框均不回显凭据。
10. 待确认思路可搜索但不自动召回；验证后能在对话引用，归档后不再自动引用。已保存引用可打开原记忆，历史来源不变。
11. 自定义 CA 加密持久化且不回显，留空 / 清除 / 换址规则生效；错误 CA、主机名不匹配、私钥或叶子证书拒绝，不能关闭 TLS 校验或污染其他连接信任。
12. 获取模型支持未保存的新密钥与相同目标的已保存密钥；接口 `POST /api/console/llm/models` 同样要求认证、控制台写头和同源校验。无凭据、换址复用、清除密钥、版本冲突均拒绝；重定向不跟随，异常不泄密，获取不修改已保存配置。
13. 获取后可选择模型或手填，选择后须保存才能测试；加载、空态、错误和目录截断反馈明确，窄屏无整体横向溢出。保存、登出或更换获取上下文后，旧请求结果不得污染页面。
14. 启用连接发现后自动保存部署摘要，未选择时不会诊断或恢复；可忽略、手动接管、查看方案及关联对话。相同资源代次不重复建单，租约、身份和版本检查禁止重复及迟到处理。
15. 模型认证、权限、限流、模型不支持、重定向、上游错误、超时和异常格式显示可区分类别，无原始正文或凭据泄漏；错误请求单次尝试。失败轮次在两种主库持久化，原身份重放不再调用模型，手动新请求可继续；页面“重新提问”本身不发送请求。
16. 新回复与历史成功回复均支持 Markdown 段落、列表、代码块和表格；代码保持字面文本，长代码 / 宽表格局部滚动。脚本、事件属性、危险协议和图片不能成为可执行或自动加载内容；用户、失败和处理中消息仍为纯文本，渲染不可用时不丢失回复。
17. 对话勾选只读排查后实际执行受控 API 请求，先保存执行意图；403 明确资源权限，模型失败仍可查看采证，原消息重放不重新读取。

sub2api 已完成模型目录读取与 gpt-6.1-sol 最小连接测试；两条导入连接已完成真实 Pod 只读检查。DashScope 原生模型目录目前仅通过本机契约测试；上海站点已完成真实Graph与模型只读诊断，事件和日志仍有403缺口；平台恢复、组织身份认证和生产网络策略仍需现场联调。模型目录可见与单次连接成功均不能代替完整诊断验收。

## 平台目录与诊断错误

部署任务页增加可选的平台站点目录，覆盖尚未创建 CR 的阶段，按服务端授权分页同步；默认关闭，不把页面 KubeSphere 凭据当作平台或恢复凭据。用户可查看阶段、选择同集群连接并显式加入项目 namespace 监控，发现后再决定调查；只读关联使用专用目录详情，不依赖恢复验收配置；详细范围见部署发现 PRD。

恢复转交的生命周期版本和验收目录从平台读取，不允许用户猜测 CR 版本。案例的记忆摘要读取故障不隐藏主任务与批准操作，而显示学习缺口。Graph 诊断与命令规划复用聊天的本地安全 LLM 错误分类，解析失败单独标记；回退规则手册时保留错误类别，不回显上游正文或自动增加模型重试。
